# gpui-py — Research brief (2026-11-03)

Compiled from 4 scout agents (2× Grok 4.6, 2× Haiku). Items marked ✅ were re-checked directly.

## 1. Upstream stack — what we pin

| Item | Fact |
|---|---|
| gpui-component | ✅ Renamed **longbridge/gpui-kit** (GitHub 301). crates.io name still `gpui-component`, ✅ **v0.9.0 (2026-11-02)**. ~weekly releases, breaking minors. Apache-2.0. ~19k stars, ~121 open issues. |
| GPUI used by gpui-kit | ✅ `gpui = { package = "gpui-pre", version = "=0.3.11" }` + `gpui_platform = { package = "gpui-pre-platform", "=0.3.11", features = ["font-kit","x11","wayland","runtime_shaders"] }`. Snapshot of `zed@f816e1f`. |
| Official crates.io `gpui` | 0.2.2 (2025-10-22), old monolith, Blade on Linux. **Do not use / do not mix.** |
| Rust | Zed pins 1.98.1, edition 2024 → "latest stable". |
| PyO3 | 0.30.x. `with_gil`→`Python::attach`, `allow_threads`→`Python::detach`. Store callbacks as `Py<PyAny>`. |
| maturin | 1.16.0. `PyO3/maturin-action@v1` + PyPI trusted publishing. |

**Rule:** exact-pin gpui-kit and inherit its `gpui-pre` pin. Unpinned/mixed GPUI families produce "two gpui type universes" (gpui-kit#2532, #3156).

## 2. API shape (current)

- Startup: `gpui_kit::application().run(|cx| …)`; `gpui_kit::init(cx)`; `gpui_kit::open_window(opts, cx, |_, cx| cx.new(|_| View))` — reportedly wraps in `Root` (UNVERIFIED in code).
- Core traits: `Render` (entity-backed), `RenderOnce` (consumed component), new `View` trait on Zed main (may or may not be in f816e1f).
- `on_click(|&ClickEvent, &mut Window, &mut App|)` — requires `.id(...)` on divs.
- Button: `Button::new(id).label(..).primary().on_click(..)`; variants: primary, secondary, danger, warning, success, info, ghost, link, text.
- Input: `cx.new(|cx| InputState::new(window, cx).placeholder(..))`, `cx.subscribe_in(&state, window, |.., InputEvent::Change| ..)`, render `Input::new(&state)`. Keep the `Subscription` alive.
- `ListDelegate`: `items_count`, `render_item`, `set_selected_index` (+ defaults).
- `TableDelegate`: `columns_count`, `rows_count`, `column`, `render_td`.
- Theme: `Theme::global(cx)`, `Theme::change(ThemeMode::Dark, window, cx)`, `Theme::sync_system_appearance`.
- Built-in charts: Line, Bar, Area, Pie, Candlestick, Radar, Sankey.
- Examples: `cargo run` (story gallery), `cargo run -p hello_world`.

## 3. Platforms

| OS | Renderer | Build needs | Notes |
|---|---|---|---|
| macOS | Metal | Xcode CLT; **full Xcode not needed** because gpui-kit enables `runtime_shaders` | Must run on main thread. IME/CJK panics open (zed#49860). |
| Windows | DirectX 11 + DirectWrite | MSVC Build Tools + Windows SDK ≥10.0.20348 (+ rc.exe) | Needs Common Controls v6 manifest. Open: IME dual-insert (zed#56327), ARM64 atlas growth (#56349), Tabs/Select bugs in gpui-kit. |
| Linux | **wgpu/Vulkan** (Blade removed Feb 2026) | clang, cmake, fontconfig-dev, wayland-dev, libxkbcommon-x11-dev, libx11-xcb-dev, Vulkan loader | Wayland + X11. Recurring: hybrid GPU / NVIDIA+Wayland / old drivers (zed#52517 open S1). lavapipe works as fallback. |

## 4. Distribution (wheels)

- Precedents: Slint (abi3 3.10+, **manylinux_2_35**, does not bundle Wayland/X11), wgpu-py (manylinux_2_28, no Vulkan ICD bundled).
- manylinux whitelist allows `libX11`, `libGL`; **not** wayland-client, xkbcommon, fontconfig, vulkan, xcb.
  - Keep GPUI's `dlopen` for Wayland and fontconfig; rely on host Vulkan; xkbcommon likely gets grafted by auditwheel (needs XKB data on host).
- Nobody has published building GPUI inside a manylinux container → **must spike early** (target manylinux_2_28 or 2_35).
- Strip symbols (gpui-kit shell: 106 MB → 78 MB). Expect tens of MB per wheel.
- Free-threaded Python needs separate wheels (cp314t / abi3t) — defer.

## 5. CI / headless

- `#[gpui::test]` / `TestAppContext` runs without a display on all 3 OS.
- Linux has a headless platform (windows lay out, draw nothing). gpui-kit README advertises headless component tests.
- Real windows on Linux CI: Xvfb + lavapipe. macOS/Windows runners can open windows.

## 6. Licenses

- GPUI: Apache-2.0. gpui-kit: Apache-2.0 (docs CC BY 4.0). Lucide icons (ISC) bundled → include notice.
- Zed editor crates (`ui`, `workspace`, …) are GPL — never depend on them. GPL leak in GPUI graph fixed Sep 2026; still run `cargo-deny`.
- GPUI uses system fonts; missing fallback fonts can panic at startup.

Self-described "Slop port of gpui-kit to python." Pins Kit 0.7.1. | Same architecture as ours. Read for lessons (property batching, async callbacks); don't build on it. |

## 8. Plan changes

1. Depend on `gpui-component =0.9.0` (exact) and inherit `gpui-pre =0.3.11`. Name everything "gpui-kit" in docs.
2. Python ≥3.10 abi3 (beats gpyui's 3.12 floor).
3. Day-one spike adds: `cargo run -p hello_world` from gpui-kit on Linux **and** a manylinux_2_28 container build attempt.
4. Week 1: confirm Windows early (most open UI bugs there).
5. Doctor script checks: Vulkan loader + ICD, Wayland/X11, fonts, xkbcommon.
6. Pin-bump process: one PR per gpui-kit release, run tests, never float.
